# feedbackbancario
feedback
Quero que a IA analise os feedbacks dos clientes de um banco para entender quais são os principais problemas, reclamações, elogios e assuntos que aparecem com mais frequência.

Essa análise será usada pela equipe de atendimento e experiência do cliente para entender melhor as dificuldades dos clientes e ajudar a decidir quais pontos precisam de melhorias.

Os dados podem ter informações como data do comentário, canal de atendimento, produto ou serviço envolvido, comentário do cliente e nota de satisfação.

Na análise, quero que a IA:

* Separe os comentários por assuntos parecidos.
* Identifique se o comentário é positivo, negativo ou neutro.
* Mostre quais problemas aparecem com mais frequência.
* Destaque os principais elogios dos clientes.
* Identifique pontos que podem ser melhorados.
* Use alguns exemplos dos comentários para mostrar de onde vieram as conclusões.
* Sugira ações que possam ajudar a melhorar os problemas encontrados.

O resultado deve ser fácil de entender, começando com um resumo dos principais pontos e depois uma tabela mostrando os temas, o tipo de feedback, os problemas ou elogios encontrados e as possíveis ações.

A IA deve usar somente as informações fornecidas. Não deve inventar números, informações ou conclusões. Se os dados não forem suficientes para chegar a alguma conclusão, deve informar isso.

Também é importante não mostrar dados pessoais dos clientes.

A resposta deve ser clara, objetiva e prática, para que a equipe consiga entender rapidamente os principais problemas e pensar nas próximas ações.
